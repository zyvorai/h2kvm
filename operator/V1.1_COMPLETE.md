## 🆕 NEW FEATURES IN v1.1

### 1. S3 Source Support ✅

**Implementation**: `pkg/sources/`

**Capabilities**:
- Parse S3 URLs (`s3://bucket/path/to/disk.vmdk`)
- Retrieve AWS credentials from Kubernetes secrets
- Generate presigned URLs (12-hour validity)
- Custom S3 endpoints (MinIO, Ceph RGW, DigitalOcean, Wasabi, Backblaze)
- Regional endpoint configuration
- Temporary credentials with session tokens

**Supported Storage**:
- AWS S3
- MinIO
- Ceph RGW
- DigitalOcean Spaces
- Wasabi
- Backblaze B2

**Usage Example**:
```yaml
apiVersion: h2kvm.io/v1alpha1
kind: HyperConversion
metadata:
  name: vmdk-from-s3
spec:
  source:
    url: "s3://my-bucket/vms/disk.vmdk"
    format: vmdk
    endpoint: "https://minio.example.com"  # Optional
    region: "us-east-1"                     # Optional
    secretRef:
      name: s3-credentials
  storage:
    size: 50Gi
  vm:
    cpu: 4
    memory: 8Gi
```

**Secret Format**:
```yaml
apiVersion: v1
kind: Secret
metadata:
  name: s3-credentials
type: Opaque
data:
  accessKeyID: <base64-encoded>
  secretAccessKey: <base64-encoded>
  sessionToken: <base64-encoded>  # Optional
```

### 2. Python Worker Integration ✅

**Implementation**: `pkg/workers/`

**Capabilities**:
- Build Kubernetes Job specs for Python worker pods
- Monitor job status, logs, and progress
- Support offline fixes (fstab, grub, initramfs, SELinux)
- Privileged containers for VMCraft/qemu-img
- Environment-based configuration
- Service account support
- Resource limits and node selectors

**Components**:
- **JobBuilder**: Builds Job specifications
- **JobMonitor**: Monitors job status and progress
- **Client**: High-level API combining builder and monitor

**Usage Example**:
```yaml
apiVersion: h2kvm.io/v1alpha1
kind: HyperConversion
metadata:
  name: vmdk-with-fixes
spec:
  source:
    url: "http://example.com/disk.vmdk"
    format: vmdk
  storage:
    size: 50Gi
  conversion:
    offlineFixes: true  # Enable Python worker
    fixFstab: true
    fixGrub: true
    fixInitramfs: true
    fixSELinux: true
    compression: zstd
    timeout: 3600
  vm:
    cpu: 4
    memory: 8Gi
```

**Environment Variables Passed to Worker**:
- `HYPERCONVERSION_NAME`: Resource name
- `SOURCE_FORMAT`: Source disk format
- `TARGET_FORMAT`: Target format (qcow2)
- `DATAVOLUME_NAME`: DataVolume name
- `DISK_PATH`: Disk path in container
- `COMPRESSION`: Compression type
- `OFFLINE_FIXES_ENABLED`: "true" if enabled
- `FIX_FSTAB`, `FIX_GRUB`, `FIX_INITRAMFS`, `FIX_SELINUX`: Individual fixes
- `TIMEOUT_SECONDS`: Conversion timeout

**Files**:
- `pkg/workers/job_builder.go` - Job spec builder (280 lines)
- `pkg/workers/job_monitor.go` - Job monitoring (220 lines)
- `pkg/workers/client.go` - High-level API (140 lines)
- `pkg/workers/README.md` - Documentation (550 lines)

**Security**:
- Privileged containers with `CAP_SYS_ADMIN`
- Required for VMCraft and qemu-img
- Dedicated service account
- Volume mounts: DataVolume PVC + host `/dev`

### 3. Resource Quotas/Rate Limiting ✅

**Implementation**: `pkg/queue/`

**Capabilities**:
- Concurrent migration limits (configurable, default: 5)
- Rate limiting per time window (configurable, default: 20/hour)
- FIFO queue for pending migrations
- Queue position tracking
- Real-time statistics
- Cluster state synchronization
- Automatic cleanup of old records

**Configuration**:
```go
config := &queue.Config{
    MaxConcurrent:   10,              // 10 simultaneous migrations
    RateLimitWindow: 1 * time.Hour,   // 1 hour window
    MaxPerWindow:    50,               // 50 migrations per hour
}
mq := queue.NewMigrationQueue(config, k8sClient)
```

**API**:
- `CanStart(hc)` - Check if migration can start
- `Enqueue(hc)` - Add to pending queue
- `Start(hc)` - Mark as running
- `Complete(hc)` - Mark as completed
- `GetNext()` - Get next from queue (FIFO)
- `GetPosition(hc)` - Get queue position
- `GetStats()` - Get queue statistics
- `SyncWithCluster(ctx)` - Sync with cluster state

**Controller Integration**:
```go
// In reconcilePending()
canStart, reason := mq.CanStart(hc)
if !canStart {
    mq.Enqueue(hc)
    hc.Status.Phase = "Queued"
    position := mq.GetPosition(hc)
    hc.Status.Message = fmt.Sprintf("Queued at position %d: %s", position, reason)
    return ctrl.Result{RequeueAfter: 30 * time.Second}, nil
}

mq.Start(hc)
hc.Status.Phase = "Uploading"
// Create DataVolume...
```

**Status Updates**:
```
Phase: Queued
Message: Queued at position 3 (running: 5/5, pending: 12)
```
