# Architecture Guardrails

This project uses a baseline-driven architecture test to enforce layering incrementally.

## Layering Test

- Test file: `tests/unit/test_architecture/test_layering.py`
- Baseline file: `tests/unit/test_architecture/layering_baseline.json`

The test computes internal imports for `h2kvm/` and enforces these rules:

1. Non-interface modules must not import interface modules.
2. Domain modules must not import application modules.
3. Domain modules must not import interface modules.
4. Application modules must not import interface modules.

Only **new** violations fail CI. Existing violations are captured in the baseline file.

## Commands

Generate dependency map artifacts:

```bash
make architecture-map
```

Run architecture guardrail tests:

```bash
make architecture-check
```

Regenerate baseline intentionally (for planned structural changes):

```bash
UPDATE_ARCH_BASELINE=1 pytest -q tests/unit/test_architecture/test_layering.py
```

## Dependency Map Outputs

- `docs/meta/dependency-map.json` (full module/package graph)
- `docs/meta/dependency-map.md` (human-readable summary)

These are generated by `scripts/generate_dependency_map.py`.
