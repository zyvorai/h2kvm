Pre-Flight Checklist (Automated)

# Run on each target KVM host
h2kvmctl doctor --json | jq '.checks[] | select(.status != "pass")'

# Critical checks:
# - KVM module loaded
# - QEMU version >= 6.0

# - Disk space >= 2x largest VM
# - Network bridge exists + UP
# - VirtIO drivers available
# - OVMF firmware installed

# Gate: ALL critical checks must pass

Boot Test Automation

Automatically verify every VM boots successfully after conversion.

Automated Boot Test Script

#!/bin/bash
# boot-test.sh — Verify VM boots and reaches network
VM_NAME="$1"
TIMEOUT=120
BRIDGE="br0"

echo "[TEST] Starting boot test for $VM_NAME..."

# Start VM
virsh start "$VM_NAME" 2>/dev/null
if [ $? -ne 0 ]; then echo "[FAIL] Cannot start $VM_NAME"; exit 1; fi

# Wait for VM to get IP address
echo "[TEST] Waiting for IP address (timeout: ${TIMEOUT}s)..."
for i in $(seq 1 $TIMEOUT); do
    IP=$(virsh domifaddr "$VM_NAME" 2>/dev/null | grep -oP '(\d+\.){3}\d+')
    if [ -n "$IP" ]; then
        echo "[PASS] $VM_NAME got IP: $IP (${i}s)"
        break
    fi
    sleep 1
done

if [ -z "$IP" ]; then echo "[FAIL] No IP after ${TIMEOUT}s"; virsh destroy "$VM_NAME"; exit 1; fi

# Test SSH connectivity (Linux VMs)
echo "[TEST] Testing SSH connectivity..."
for i in $(seq 1 30); do
    ssh -o ConnectTimeout=3 -o StrictHostKeyChecking=no "$IP" "hostname" &>/dev/null
    if [ $? -eq 0 ]; then echo "[PASS] SSH accessible at $IP"; exit 0; fi
    sleep 2
done

# Test RDP connectivity (Windows VMs)
nc -z -w 3 "$IP" 3389 &>/dev/null
if [ $? -eq 0 ]; then echo "[PASS] RDP accessible at $IP (Windows)"; exit 0; fi

echo "[WARN] VM booted with IP but SSH/RDP not accessible"
exit 2

Application Smoke Tests

Verify applications work correctly after migration — templates for common services.

Smoke Test Templates

Web Application

#!/bin/bash
# smoke-test-web.sh
VM_IP="$1"
echo "[TEST] Web app smoke test..."

# HTTP response
HTTP_CODE=$(curl -s -o /dev/null -w "%{http_code}" \
  "http://$VM_IP/")
[ "$HTTP_CODE" = "200" ] && echo "[PASS] HTTP 200" \
  || echo "[FAIL] HTTP $HTTP_CODE"

# HTTPS
HTTP_CODE=$(curl -sk -o /dev/null -w "%{http_code}" \
  "https://$VM_IP/")
[ "$HTTP_CODE" = "200" ] && echo "[PASS] HTTPS 200" \
  || echo "[FAIL] HTTPS $HTTP_CODE"

# API health endpoint
HEALTH=$(curl -s "http://$VM_IP/api/health" | jq -r '.status')
[ "$HEALTH" = "ok" ] && echo "[PASS] API healthy" \
  || echo "[FAIL] API: $HEALTH"

Database Server

#!/bin/bash
# smoke-test-db.sh
VM_IP="$1"
echo "[TEST] Database smoke test..."

# PostgreSQL connection
psql -h "$VM_IP" -U app_user -d appdb -c "SELECT 1" \
  &>/dev/null && echo "[PASS] PostgreSQL connected" \
  || echo "[FAIL] PostgreSQL connection failed"

# Row count check (compare to pre-migration)
COUNT=$(psql -h "$VM_IP" -U app_user -d appdb -tAc \
  "SELECT count(*) FROM orders")
PRE_COUNT=1542387  # from pre-migration baseline
[ "$COUNT" = "$PRE_COUNT" ] \
  && echo "[PASS] Row count matches ($COUNT)" \
  || echo "[FAIL] Row count mismatch: $COUNT vs $PRE_COUNT"

# Replication status (if replica)
psql -h "$VM_IP" -U postgres -c "SELECT * FROM pg_stat_replication" \
  &>/dev/null && echo "[PASS] Replication active"

Windows / Active Directory

# smoke-test-windows.ps1 (run via WinRM)
# RDP accessibility
Test-NetConnection -ComputerName $VM_IP -Port 3389
# [PASS] RDP port open

# Domain services (if DC)
Get-ADDomainController -Filter *
# [PASS] AD DS responding

# DNS resolution
Resolve-DnsName -Name corp.local -Server $VM_IP
# [PASS] DNS resolution working

# File share accessibility
Test-Path "\\$VM_IP\shared$"
# [PASS] File share accessible

# SQL Server (if applicable)
Invoke-Sqlcmd -ServerInstance $VM_IP \
  -Query "SELECT @@VERSION"
# [PASS] SQL Server responding

Generic Service Check

#!/bin/bash
# smoke-test-services.sh
VM_IP="$1"
SERVICES_FILE="$2"  # services.txt

# Test each service port
while IFS=, read -r name port protocol; do
  if [ "$protocol" = "tcp" ]; then
    nc -z -w 3 "$VM_IP" "$port" &>/dev/null
    [ $? -eq 0 ] \
      && echo "[PASS] $name (TCP/$port)" \
      || echo "[FAIL] $name (TCP/$port)"
  fi
done < "$SERVICES_FILE"

# Example services.txt:
# ssh,22,tcp
# http,80,tcp
# https,443,tcp
# postgresql,5432,tcp
# redis,6379,tcp
# elasticsearch,9200,tcp

Regression & Soak Testing

Extended validation to catch issues that only appear under sustained load.

24-Hour Soak Test

  • Run VM under production-like load for 24 hours
  • Monitor: CPU, memory, disk I/O, network, swap usage
  • Check for: memory leaks, disk space growth, log rotation
  • Verify: no kernel panics, no OOM kills, no service crashes
  • Compare metrics to VMware 24-hour baseline
  • Tool: stress-ng --cpu 4 --vm 2 --vm-bytes 2G --timeout 86400
  • Gate: zero errors in 24 hours = pass

Failover Testing

  • Kill VM process unexpectedly: kill -9 $(pgrep qemu)
  • Verify Pacemaker restarts VM on same or different host
  • Measure RTO: time from failure to VM responding
  • Test live migration: virsh migrate --live vm host2
  • Verify application state preserved after migration
  • Test storage failover (if Ceph): kill OSD, verify recovery
  • Gate: RTO < 5 minutes for automated failover

Network Partition Test

  • Simulate network outage to VM: iptables -A FORWARD -d $VM_IP -j DROP
  • Verify application handles gracefully (timeouts, retries)
  • Restore network: iptables -D FORWARD -d $VM_IP -j DROP
  • Verify application recovers automatically
  • Check database replication catches up
  • Verify monitoring alerts fired during outage
  • Gate: application recovers within 60 seconds of network restore

Backup / Restore Test

  • Take backup of migrated VM
  • Restore to a different name/location
  • Boot restored VM, verify data integrity
  • Measure restore time (RTO for backup recovery)
  • Test with: QCOW2 snapshot, BorgBackup, Velero
  • Verify backup encryption works correctly
  • Gate: successful restore with data verification

Test Automation Pipeline

Integrate all tests into CI/CD for fully automated migration validation.

Automated Test Pipeline

# .gitlab-ci.yml — Migration Test Pipeline
stages: [preflight, convert, boot-test, smoke-test, perf-test, accept]

preflight:
  stage: preflight
  script:
    - h2kvmctl doctor --json > doctor-report.json
    - h2kvmctl convert --config $CONFIG --dry-run --json > dry-run.json
    - "[ $(jq -r '.status' dry-run.json) = 'ready' ]"
  artifacts: { paths: [doctor-report.json, dry-run.json] }

convert:
  stage: convert
  script:
    - h2kvmctl convert --config $CONFIG --json > conversion.json
    - "[ $(jq -r '.status' conversion.json) = 'success' ]"
  artifacts: { paths: [conversion.json] }

boot-test:
  stage: boot-test
  script:
    - for vm in $(jq -r '.vms[].name' $CONFIG); do ./boot-test.sh "$vm"; done
  allow_failure: false

smoke-test:
  stage: smoke-test
  script:
    - for vm in $(jq -r '.vms[].name' $CONFIG); do ./smoke-test.sh "$vm"; done

perf-test:
  stage: perf-test
  script:
    - ./perf-baseline.sh --compare vmware-baseline.json --output kvm-results.json
    - h2kvmctl perf-report --baseline vmware-baseline.json --current kvm-results.json

accept:
  stage: accept
  script:
    - echo "All automated tests passed. Manual acceptance required."
    - h2kvmctl evidence-package --dir evidence/ --sign
  when: manual  # Requires human approval
