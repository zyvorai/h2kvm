hypersdk

Multi-Cloud VM Export Daemon

hyper2kvm

VM Migration Toolkit
Python + VMCraft engine (480+ APIs). 8 input formats. 35+ OS support. Automated offline fixes (GRUB, fstab, VirtIO, initramfs). 5-7x faster than virt-v2v.

Stage: PyPI published. 10K+ downloads. 1,483 tests.

virtcraft

KubeVirt CLI Manager
Rust-based CLI for KubeVirt VMs. Templates, profiles, blueprints, snapshots. Interactive TUI dashboard. Shell completions. Single binary.

Stage: Functional. Deployed on production server.
