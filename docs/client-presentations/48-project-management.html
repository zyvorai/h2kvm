Project Charter

Executive-approved document that authorizes the migration project.

Project Overview

  • Project Name: VMware to KVM Infrastructure Migration
  • Sponsor: CTO / VP Infrastructure
  • PM: Migration Project Manager
  • Start Date: [Date]
  • Target Completion: [Date + 12 weeks]
  • Budget: $[X] (hardware + labor + contingency)

Business Case: Eliminate $[X]/yr VMware licensing costs by migrating [N] VMs to open-source KVM. Broadcom acquisition has increased licensing costs by [X]% with [X]-year lock-in commitment required. Migration eliminates vendor dependency and reduces annual infrastructure costs by [X]%.

Scope & Success Criteria

  • In Scope:
  • Migrate [N] VMs from VMware ESXi to KVM
  • Deploy [N] KVM hosts with HA clustering
  • Configure monitoring, backup, and DR
  • Decommission VMware infrastructure
  •  
  • Out of Scope:
  • Application refactoring or containerization
  • Hardware refresh (using existing or planned servers)
  •  
  • Success Criteria:
  • 100% VMs migrated with < 4 hours total downtime per VM
  • Performance within 10% of VMware baseline
  • All compliance requirements maintained
  • VMware licenses terminated by [date]
