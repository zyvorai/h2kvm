💡 What is HyperSDK?

A unified platform to discover, export, convert, and deploy virtual machines across any cloud or hypervisor — all in one place.

⚙️ What it brings to the table

  • Multi-cloud VM discovery (VMware, AWS, Azure, more)
  • Seamless export (VMDK, QCOW2, RAW, OVA…)
  • Automated conversion powered by h2kvm
  • Direct deployment to KVM / KubeVirt
  • Observability + real-time monitoring

🔥 Why it matters

Today’s migration tools are fragmented — you stitch together exporters, converters, scripts, and hope nothing breaks. HyperSDK changes that.

  • One pipeline
  • One platform
  • Zero guesswork
