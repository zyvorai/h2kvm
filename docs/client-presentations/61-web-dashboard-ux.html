Security Features

  • PAM authentication against system users
  • HttpOnly session cookies (SameSite=Strict)
  • 32-byte random hex session tokens
  • In-memory session store (no external DB)
  • API key fallback for CLI/scripts
  • Public endpoints: /health, /auth/* only
  • All API routes require valid session
  • Username character validation
  • CORS middleware for browser access

Auth Flow

POST /api/v1/auth/login
  → PAM verify (pam.StartFunc "login")
  → Create session (32-byte token)
  → Set-Cookie: h2kweb_session=<token>

GET /api/v1/auth/session
  → Validate cookie → {authenticated: true}

POST /api/v1/auth/logout
  → Remove session → Clear cookie
