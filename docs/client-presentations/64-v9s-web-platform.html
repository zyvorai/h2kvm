Console Access

Three console types with full keyboard control.

🖥️

VNC Graphical Console

Full desktop experience via noVNC. Scales to viewport. Fullscreen mode. Auto-reconnect on disconnect.

Sendkey Toolbar

  • Ctrl+Alt+Delete — Login screen / task manager
  • Ctrl+Alt+F1 — Switch to text console
  • Ctrl+Alt+F2 — Switch to TTY2
  • Ctrl+Alt+F7 — Switch to graphical desktop

Uses XK keysym codes via RFB protocol. Keys that browsers intercept are sent directly to the VM.

⌨️

Serial Console

xterm.js terminal emulation via KubeVirt serial console WebSocket. Ideal for headless VMs, boot troubleshooting, GRUB access.

SSH Console

Web-based SSH terminal for VMs with network connectivity. Configurable port and credentials. Direct IP-based connection.

Storage & Network

Disk management, ISO mount, and network interface control.

💽

Storage Management

  • View attached volumes with type, size, and storage class
  • Mount ISO — Attach container disk images as CDROM (SATA)
  • Duplicate protection — replaces existing CDROM entries
  • Modal dialog with loading state, error display, auto-close on success
  • Storage class listing for PVC provisioning
🌐

Network Management

  • View interfaces with IP, MAC, state from VMI guest agent
  • Add Network — Pod or Multus network types
  • Binding models: Bridge, Masquerade (NAT), SR-IOV
  • Duplicate name prevention with inline error
  • Guest OS information (OS name, version, kernel)

Monitoring & Metrics

Real-time performance data via WebSocket streaming.

📈

CPU Usage

Real-time area chart with green gradient. Percentage display. 60-point history buffer.

📊

Memory Usage

Blue gradient area chart. Absolute and percentage values. Tracks allocation vs usage.

🔄

Network I/O

Dual-line chart: RX (purple) and TX (amber). KB/s throughput. Bidirectional traffic view.

💿

Disk I/O

Dual-line chart: Read (cyan) and Write (red). KB/s throughput. Identifies storage bottlenecks.

🏪

Metrics Store

Zustand-based client-side store. Per-VM history (60 data points per metric). No re-fetch on tab switch. WebSocket auto-reconnect.

Events & Logs

📋

Kubernetes Events

Filtered by VM. Normal/Warning type badges. Reason, message, timestamp. Tracks scheduling, lifecycle, and error events.

📜

VM Logs

Two sources: Console log (guest output) and Compute log (QEMU/libvirt). Terminal-style rendering. Refresh button and source selector.

Security & Access

Enterprise authentication and authorization.

🔐

PAM Authentication

Login via Linux PAM. Supports local accounts, LDAP, SSSD, and any PAM-compatible backend. No separate user database.

🎫

JWT Sessions

Token-based sessions with configurable expiry. Bearer token on every API request. Secure cookie storage in browser.

🔒

HTTPS / TLS

Nginx TLS termination with self-signed or CA certificates. All traffic encrypted. Security headers (X-Frame-Options, nosniff).

🛡️

Kubernetes RBAC

VM operations respect K8s RBAC. Users only manage VMs in authorized namespaces. 403 on unauthorized actions.

API Security

  • All endpoints require Bearer token authentication
  • Input validation — K8s name format enforcement on all user-supplied fields
  • CORS and security headers enforced
  • Request/response logging with tracing
  • WebSocket connections authenticated before upgrade
