Data Protection

Your VM data never leaves your control during migration.

🔒

No Cloud Upload

h2kvm runs entirely on-premises. Disk images are converted locally. No data sent to external services, APIs, or analytics platforms. Zero telemetry.

🛡️

Encryption at Rest

Output qcow2 images support LUKS encryption. Source VMDKs with encrypted vSAN/VMFS are handled natively. Keys never leave your infrastructure.

🔐

Encryption in Transit

vSphere exports use TLS 1.2+. SSH-based remote exports use ed25519/RSA keys. KubeVirt uploads via HTTPS. No plaintext disk transfers.

🗑️

Secure Cleanup

Temporary files in /tmp auto-deleted after conversion. Working directories cleaned on completion. No residual disk data left behind.

Air-Gapped Migration

For classified, SCIF, or disconnected environments: h2kvm works fully offline. Install via RPM/DEB from USB. Export VMDKs to external drive. Convert on isolated network. No internet required at any stage.

Security Hardening

What h2kvm does to harden migrated VMs.

🔑

Credential Handling

vCenter passwords via env vars or vault references. Never stored in YAML. vc_password_env indirection prevents credential leaks in configs.

🐧

SELinux Relabel

Triggers autorelabel on first boot after migration. Ensures all file contexts are correct for the new KVM environment. No permissive mode shortcuts.

🧹

VMware Tools Removal

Removes open-vm-tools, VMware agents, and Hyper-V integration services. Eliminates unnecessary attack surface from source hypervisor.

🔧

Driver Hardening

Injects only required virtio drivers (blk, net, scsi). No unnecessary kernel modules loaded. Minimal attack surface on target.

📝

Audit Trail

Every migration logged with structured JSON: timestamps, trace IDs, source/target paths, user, exit codes. Ship to SIEM for compliance.

🏗️

Reproducible Builds

YAML configs define exact migration parameters. Same config = same result. Auditors can verify any migration was performed correctly.

Pre-Flight Security Checks

  • Validates source disk integrity before conversion (extent size, descriptor parsing)
  • Checks target directory permissions (no world-writable output)
  • Verifies KVM/libvirt security context (SELinux labels on output images)
  • Warns on insecure TLS (self-signed vCenter certs flagged in logs)
  • Detects and reports Windows VMs needing VirtIO driver injection
