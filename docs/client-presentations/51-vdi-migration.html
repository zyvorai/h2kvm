Migration Workflow

Step-by-step: Horizon desktop pool to KVM + SPICE/RDP desktops.

Step 1: Export Horizon Master Image

  • In Horizon Admin: identify master/golden image VM
  • Export as OVA: govc export.ovf -vm /DC/vm/golden-win11
  • Or export VMDK from datastore directly
  • Includes: OS, apps, profile settings, GPOs
  • Note: linked clones won't export — use full clone or master

Step 2: Convert with h2kvmctl

h2kvmctl convert \
  --source golden-win11.vmdk \
  --format qcow2 --compress \
  --virtio-drivers /usr/share/virtio-win/virtio-win.iso \
  --emit-domain-xml

# Creates: golden-win11.qcow2 (template)

Step 3: Create Desktop Pool

#!/bin/bash
# create-vdi-pool.sh — create N desktop VMs
TEMPLATE="golden-win11.qcow2"
POOL_SIZE=50
BRIDGE="br-vdi"

for i in $(seq 1 $POOL_SIZE); do
  NAME="desktop-$(printf '%03d' $i)"
  # Linked clone (fast, space-efficient)
  qemu-img create -f qcow2 \
    -b $TEMPLATE -F qcow2 \
    /var/lib/libvirt/images/${NAME}.qcow2
  # Define VM
  virt-install --name $NAME \
    --ram 4096 --vcpus 2 \
    --import --disk /var/lib/libvirt/images/${NAME}.qcow2 \
    --network bridge=$BRIDGE,model=virtio \
    --graphics spice --noautoconsole
done
echo "Created $POOL_SIZE desktop VMs"

Step 4: Connect Users

  • SPICE: remote-viewer spice://kvm-host:5900
  • RDP: mstsc /v:desktop-001.corp.local
  • Guacamole: Browser → login → click desktop name
  • Thin clients: Configurable SPICE/RDP endpoints
  • LDAP auth maps user → assigned desktop VM
  • User profile stored on network share (roaming)
