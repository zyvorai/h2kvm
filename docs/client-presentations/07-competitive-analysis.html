Key Differentiators

vs Red Hat MTV

MTV requires OpenShift ($50K+/yr). h2kvm works on any Linux + any K8s (K3s, vanilla, EKS). MTV can't deploy to standalone KVM/libvirt. h2kvm does both.

vs virt-v2v

virt-v2v is CLI-only, no TUI, no batch queue, no KubeVirt deploy, no progress streaming, no pre-flight checks. h2kvm wraps virt-v2v capabilities and adds enterprise features.

vs AWS MGN / Azure Migrate

Cloud tools only migrate TO their cloud. h2kvm migrates FROM any cloud TO any target. Perfect for repatriation — the opposite direction cloud vendors want.

vs Carbonite

Carbonite costs $3-10K/yr, requires Windows, GUI-only. No YAML automation, no KubeVirt, no air-gap support. h2kvm is free, Linux-native, fully automatable.
