Air-Gapped Migration — Zero Internet Required

For classified, SCIF, TEMPEST, or fully disconnected environments:

  • Install: Copy RPM/DEB/Python wheel + Go binary via USB or approved media
  • Export: Transfer VMDKs/VHDs via encrypted external drive (FIPS-approved if required)
  • Convert: Run h2kvm on isolated network — no internet, no DNS, no NTP dependency
  • Deploy: virsh define locally or kubectl apply on air-gapped K8s cluster
  • No phone-home: h2kvm has zero network calls — no license check, no update check, no telemetry
  • Verified: Checksums (SHA256) for all binaries — verify integrity before deployment

hypersdk Security Architecture

Enterprise-grade security built into every layer of the daemon.

Authentication

  • JWT tokens: Short-lived, signed, with expiry
  • API keys: For service-to-service auth
  • Session management: Token rotation, forced logout
  • Password hashing: bcrypt with configurable cost
  • Multi-factor: Extensible auth port interface
  • No default passwords — explicit setup required

RBAC Authorization

  • 3 roles: admin, operator, viewer
  • 6 actions: create, read, update, delete, export, cancel
  • Resource-level: jobs, schedules, providers, config, users
  • Permission matrix enforced at API middleware layer
  • Denied access logged to audit trail
  • Configurable per-endpoint authorization

Secret Management

  • SecretManager port: Pluggable backends
  • Vault integration: HashiCorp Vault support
  • File backend: Encrypted local secret store
  • Env vars: GOVC_PASSWORD, cloud API keys
  • Rotation: Automatic secret rotation support
  • Credentials never stored in YAML configs

Audit Logging

  • Every action logged: login, export, create/cancel/delete job
  • Fields: user, IP address, timestamp, action, resource, result
  • AuditLogger port: File-based (default), extensible to SIEM
  • Tamper detection: Append-only log with checksums
  • Queryable history for compliance reviews
  • 16+ audit event types covering full lifecycle

Network Security

  • TLS everywhere: API server, provider connections
  • Certificate rotation: Configurable TLS cert renewal
  • Rate limiting: Per-user and global request limits
  • No inbound ports required: Daemon initiates all connections
  • Works behind firewalls and NAT
  • Air-gap: zero network requirements

Credential Protection

  • vCenter passwords: vc_password_env reads from env var
  • Cloud API keys: Stored in SecretManager, not config files
  • Redaction: VCenterConfig.Redacted() masks passwords in logs
  • No plaintext: Credentials never appear in YAML, logs, or metrics
  • SSH key-based auth (no password storage)
  • Kubernetes secrets integration for K8s deployments

What Happens Without Security Hardening

Naive Migration (Without h2kvm)

  • VMware Tools still running — unnecessary services, potential info leak
  • SELinux in permissive or disabled (broken contexts)
  • Old hypervisor agents phoning home or crashing
  • Stale NIC configs with wrong firewall rules
  • Cloud agents trying to reach metadata services
  • Unnecessary kernel modules loaded
  • Result: Larger attack surface, compliance gaps

h2kvm Migration (Hardened)

  • Source hypervisor tools removed completely
  • SELinux enforcing with correct file contexts
  • Only VirtIO drivers loaded — minimal kernel surface
  • Clean network configuration — no stale rules
  • Cloud agents disabled or removed
  • UEFI/Secure Boot preserved
  • Result: Smaller attack surface, compliance-ready
