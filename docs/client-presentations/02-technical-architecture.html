hypersdk: Hexagonal Architecture

Clean separation of domain, ports, and adapters.

🎯

Domain Layer

70+ canonical Go types. Job, Schedule, VM, Cost, Carbon, Webhook, Audit, RBAC. Zero dependencies on external packages.

🔌

Ports Layer

13+ interfaces defining contracts. JobManager, ScheduleManager, CapabilityDetector, CostEstimator, CarbonTracker, AuditLogger.

🧩

Adapters Layer

Concrete implementations. REST API, provider clients, SQLite store, Prometheus metrics, webhook dispatcher, secrets vault.

Key Daemon Features

Job Scheduling

  • Cron-based scheduling with time windows
  • Retry policies with exponential backoff
  • Priority queues, concurrency limits
  • Webhook notifications on completion

Observability

  • Prometheus metrics endpoint
  • Structured JSON logging with trace IDs
  • Audit trail for all operations
  • Cost estimation per migration

Security

  • RBAC with roles and permissions
  • API key + JWT authentication
  • Secrets management (vault integration)
  • TLS everywhere, cert rotation

Enterprise Features

  • Carbon-aware scheduling (green migration)
  • Multi-tenant with namespace isolation
  • Backup and disaster recovery
  • HA with leader election

What happens to a VM disk from export to first boot.

StageWhat It DoesWhy It Matters
ValidateVMDK descriptor parsing, extent verification, boot mode detection (BIOS/UEFI), risk analysisCatches corrupt/truncated disks before wasting hours on conversion
FlattenMerge snapshot chain into single image via qemu-img convertEliminates snapshot dependencies, produces self-contained disk
ConvertVMDK/VHD/RAW to qcow2 with optional compressionqcow2 is the native KVM format — thin provisioning, snapshots, compression
Guest FixMount disk offline, fix fstab (UUID stabilization), rebuild initramfs with virtio drivers, remove VMware tools, fix GRUB, relabel SELinuxWithout this, VMs fail to boot on KVM — missing drivers, wrong device paths
DeployGenerate libvirt XML, virsh define, or create KubeVirt VirtualMachine + PVC uploadVM is ready to start — no manual XML editing or kubectl gymnastics

Guest Fix Engine (VMCraft)

Linux Fixes

  • fstab: convert device names to UUID/path
  • initramfs: inject virtio_blk, virtio_net, virtio_scsi
  • GRUB: update root= parameter, rebuild config
  • SELinux: trigger autorelabel on next boot
  • Network: remove VMware/Hyper-V NIC configs
  • VMware tools: remove open-vm-tools packages

Windows Fixes

  • VirtIO driver injection (disk, net, balloon)
  • Registry: update boot device driver stack
  • Remove VMware Tools/Hyper-V IC services
  • Fix BCD boot configuration
  • Enable serial console for headless access
  • Multi-stage: bootstrap, drivers, cleanup

zkvm: Interactive TUI

Terminal UI built with Go + Bubble Tea for guided migration.

📋

Guided Steps

Step 1: Source (auto-detect format) → Step 2: Output → Step 3: Fixes → Step 4: Deploy to Libvirt. No CLI memorization.

🔌

vSphere Integration

Auto-populate from GOVC_* env vars. Discover VMs with CPU/RAM/power state. Select, queue, migrate — all from the TUI.

📂

File Browser

Built-in fzf-style fuzzy file picker. Filters by extension (.vmdk, .ova, etc). Navigate dirs, search instantly.

📊

Live Progress

Real-time streaming of govc export progress, conversion status, and deployment steps. Progress bar with speed and ETA.
