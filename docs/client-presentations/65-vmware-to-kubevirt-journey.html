1

Export from VMware

Export VMDK via govc, OVF Tool, vSphere HTTP API, or VDDK. h2kvm supports all export methods with automatic format detection.

2

Flatten & Convert

Flatten sparse/split VMDKs into a single file. Convert to qcow2 with optional compression. Checksum validation for integrity.

3

Automated Offline Fixes

GuestKit engine mounts the image and applies deterministic fixes: GRUB repair, VirtIO drivers, fstab stabilization, initramfs rebuild, network config, serial console.

4

CDI Upload to Kubernetes

Automatic CDI (Containerized Data Importer) upload creates a PersistentVolumeClaim with the disk image. qcow2→raw conversion handled by CDI.

5

KubeVirt VM Creation

VirtualMachine manifest generated with CPU, memory, disk, and network configuration. VM boots successfully on first attempt.

6

Ongoing Management with v9s

Web-based management: console access, metrics monitoring, snapshots, storage, network, and host visibility. Full day-2 operations.

Step 1–5: Migration

One command to migrate a VMware VM to KubeVirt.

Single Command Migration

$ h2kvmctl \
  --cmd local \
  --vmdk /vmware/ubuntu-server2504.vmdk \
  --output-dir /output \
  --flatten \
  --to-output ubuntu-server2504.qcow2 \
  --out-format qcow2 \
  --fstab-mode stabilize-all \
  --regen-initramfs \
  --serial-console \
  --compress
