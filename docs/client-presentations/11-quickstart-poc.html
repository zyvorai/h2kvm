Quick Start & POC Guide

From zero to migrated VM in 30 minutes. Give this to your IT team.

Part 1: Install (5 minutes)

1

Prerequisites

Any Linux machine (Fedora, RHEL 9+, Ubuntu 22.04+). 4GB RAM, 20GB free disk. Root access.

sudo dnf install -y qemu-img libguestfs-tools  # Fedora/RHEL
# OR
sudo apt install -y qemu-utils libguestfs-tools  # Ubuntu/Debian
2

Install h2kvm

git clone https://github.com/ssahani/h2kvm.git
cd h2kvm
pip3 install -e .
# OR use the quickstart script:
sudo ./scripts/quickstart.sh
3

Install govc (for vSphere)

curl -L https://github.com/vmware/govmomi/releases/latest/download/govc_Linux_x86_64.tar.gz \
  | sudo tar xzf - -C /usr/local/bin govc
4

Verify

h2kvmctl --version   # should print version
govc version         # should print govc version

Part 2: Local Test (10 minutes)

Test with a local VMDK file — no vCenter needed.

5

Get a test VMDK 2 min

Use any existing VMDK, or download a small test image:

# Option A: Use an existing VMDK from your VMware datastore
# Option B: Download Photon OS (small, fast)
curl -LO https://packages.vmware.com/photon/5.0/Rev1/ova/photon-5.0-ova.ova
tar xf photon-5.0-ova.ova  # extracts .vmdk
6

Convert VMDK to qcow2 5 min

sudo h2kvmctl \
  --cmd local \
  --vmdk photon.vmdk \
  --output-dir ./out \
  --out-format qcow2 \
  --flatten \
  --fstab-mode stabilize-all \
  --regen-initramfs \
  --emit-domain-xml \
  --vm-name photon-test \
  --memory 1024 \
  --vcpus 2
7

Verify output 1 min

ls -lh out/                    # qcow2 file created
qemu-img info out/*.qcow2      # verify format
virsh list --all               # VM should be defined
Success criteria: qcow2 file created, VM defined in libvirt, virsh start photon-test boots successfully.

Part 3: vSphere Test (15 minutes)

Connect to your vCenter and migrate a real VM.

8

Set vCenter credentials 1 min

export GOVC_URL="https://vcenter.yourdomain.com/sdk"
export GOVC_USERNAME="administrator@vsphere.local"
export GOVC_PASSWORD="your-password"
export GOVC_DATACENTER="your-datacenter"
export GOVC_INSECURE=1   # if self-signed cert
9

Discover VMs 1 min

# Quick check:
govc ls /your-datacenter/vm/

# Or use the interactive TUI:
./zkvm/zkvm
# Press Tab to go to vSphere tab — VMs auto-discovered
10

Migrate a test VM 10-30 min

# Create migration config:
cat > test-migration.yaml <<EOF
cmd: vsphere
vcenter: vcenter.yourdomain.com
vc_user: administrator@vsphere.local
vc_password_env: GOVC_PASSWORD
dc_name: your-datacenter
vs_action: export_vm
vs_vm: your-test-vm
output_dir: ./out
out_format: qcow2
flatten: true
regen_initramfs: true
emit_domain_xml: true
vm_name: migrated-test-vm
EOF

sudo h2kvmctl --config test-migration.yaml
11

Verify migration 2 min

virsh list --all                  # VM should appear
virsh start migrated-test-vm     # Start it
virsh console migrated-test-vm   # Check console

POC VM Selection Guide

Start With

  • Non-production Linux VM (CentOS/RHEL)
  • Small disk (<20GB) for fast test
  • Standard config (no GPU passthrough)
  • Single disk, single NIC

Then Test

  • Windows Server VM (VirtIO injection)
  • Multi-disk VM (data disk preservation)
  • UEFI boot VM (firmware detection)
  • Production-like workload (DB, web server)

Common Issues & Fixes

IssueSolution
govc: certificate errorSet GOVC_INSECURE=1 or import vCenter CA cert
Permission denied on qcow2Run with sudo — KVM needs root for disk access
VM boots to GRUB rescueEnable --regen-initramfs in config
No network after bootCheck bridge config: virsh net-list
Windows BSODAdd --windows --virtio-win-iso /path/to/virtio-win.iso
