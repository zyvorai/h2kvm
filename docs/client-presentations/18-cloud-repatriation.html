Cloud-Specific Technical Details

What hyper2kvm fixes for each cloud provider — Linux and Windows.

AWS EC2 Specifics

  • Export: EBS snapshot → CreateStoreImageTask or ec2 create-snapshot + export-image to S3
  • Linux fixes: Remove AWS SSM agent, EC2 instance connect, CloudWatch agent. Fix fstab from /dev/xvda to UUID. Rebuild initramfs: replace xen-blkfront with virtio_blk
  • Windows fixes: Remove EC2Config/EC2Launch, SSM agent, CloudWatch. Inject VirtIO drivers, fix BCD
  • Networking: Remove ENI-specific configs, elastic IP associations. Clean /etc/sysconfig or netplan
  • cloud-init: Disable EC2 datasource, preserve hostname and SSH keys

Azure VM Specifics

  • Export: Managed disk snapshot → grant access (SAS URL) → download VHD via azcopy or wget
  • Linux fixes: Remove walinuxagent (waagent), Hyper-V IC daemons (hv_kvp, hv_vss). Fix fstab from /dev/sda to UUID. Rebuild initramfs: replace hv_storvsc with virtio_blk
  • Windows fixes: Remove Azure VM agent, Hyper-V IC. Inject VirtIO, fix BCD. Remove Azure diagnostics extension
  • Networking: Remove Azure-specific accelerated networking config. Clean udev rules for Mellanox/hv_netvsc
  • cloud-init: Disable Azure datasource, remove CustomData provisioning

GCP Compute Specifics

  • Export: gcloud compute images export → GCS bucket → download tar.gz containing disk.raw
  • Linux fixes: Remove google-guest-agent, google-osconfig-agent, google-compute-engine packages. Fix fstab from /dev/sda to UUID. Rebuild initramfs with VirtIO
  • Windows fixes: Remove GCP compute agent, metadata scripts. Inject VirtIO, fix BCD
  • Networking: Remove google-guest-agent NIC management. Clean /etc/netplan or ifcfg with GCP metadata references
  • cloud-init: Disable GCE datasource, remove startup-script hooks

OCI / Alibaba / OpenStack

  • OCI: Boot volume → Object Storage pre-authenticated request → download. Remove oracle-cloud-agent, fix fstab, rebuild initramfs
  • Alibaba: ECS disk snapshot → OSS export → download. Remove aliyun-cli agent, fix fstab from /dev/vda (already virtio!) to UUID
  • OpenStack: Glance image download or Cinder volume snapshot export. Disable cloud-init OpenStack datasource, fix fstab, minimal initramfs changes (often already QCOW2/VirtIO)
  • Common: All cloud exports get fstab UUID repair, initramfs rebuild, GRUB fix, network cleanup, serial console enable

hyper2kvm auto-detects the source cloud based on installed agents, driver stack, and fstab patterns. It applies the correct set of fixes for each source — no manual configuration needed. Just point it at the exported disk image.
