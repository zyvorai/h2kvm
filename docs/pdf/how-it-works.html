8 Binary Components

hyperexport

Standalone interactive VM export. Select VMs, choose format, export with progress. Works without daemon.

hypervisord

Background daemon. REST API on port 9292. Job queue, scheduling, webhooks. Runs as systemd service.

hyperctl

CLI migration commander. Create jobs, manage schedules, query status. Like kubectl for migrations.

hyperconvert

Format conversion tool. VMDK/VHD/RAW/qcow2 with progress. Standalone or daemon-integrated.

hypersdk-agent

gRPC agent for distributed export. Deploy near source infrastructure. Streams data to control plane.

hypersdk-control

Control plane for multi-agent deployments. Manages agent fleet, routes jobs, aggregates results.

hypersdk-dashboard

Web UI for monitoring. Job status, metrics, cost reports. Built-in Prometheus + Grafana integration.

hypersdk-operator

Kubernetes operator. CRDs for migration jobs. GitOps-friendly. Helm chart included.

VMCraft: Guest Fix Engine

The critical differentiator — why VMs boot on first try.

📁

fstab Stabilization

Scans /etc/fstab inside the disk image. Converts device-name entries (/dev/sda1) to UUID-based entries. Handles LVM, XFS UUID regeneration, BTRFS subvolumes. Three modes: stabilize-all, bypath-only, noop.

🔧

initramfs Rebuild

Chroots into guest OS. Injects virtio_blk, virtio_net, virtio_scsi kernel modules. Runs dracut/mkinitramfs to rebuild. Supports RHEL, Ubuntu, Debian, SUSE, Photon OS.

🖥️

GRUB Repair

Updates root= kernel parameter to match new device path. Regenerates grub.cfg. Handles both BIOS and UEFI boot. Fixes broken grubenv symlinks.

🐧

SELinux Relabel

Creates /.autorelabel trigger file. On first boot, SELinux relabels all files with correct contexts. Prevents boot failures from label mismatches.

🪟

Windows VirtIO

Mounts virtio-win.iso. Injects viostor (storage), NetKVM (network), Balloon (memory) drivers. Updates Windows registry to load VirtIO at boot. Multi-stage: bootstrap → drivers → cleanup.

🧹

Cleanup

Removes VMware Tools (open-vm-tools). Removes Hyper-V integration services. Clears stale network configs (VMXNET3 MAC bindings). Reduces attack surface.

How VMCraft Works (Under the Hood)

# 1. Connect to disk via qemu-nbd (no libguestfs needed)
sudo qemu-nbd --connect=/dev/nbd0 disk.qcow2

# 2. Detect partitions and mount
partprobe /dev/nbd0
mount /dev/nbd0p2 /mnt/guest       # root partition
mount /dev/nbd0p1 /mnt/guest/boot  # boot partition

# 3. Chroot and fix
chroot /mnt/guest /bin/bash
  # Fix fstab (UUID stabilization)
  # Rebuild initramfs (dracut --force --add virtio)
  # Update GRUB (grub2-mkconfig)
  # Create /.autorelabel

# 4. Unmount and disconnect
umount -R /mnt/guest
qemu-nbd --disconnect /dev/nbd0

Built-in fzf-style fuzzy file picker. Filters by extension. Navigate dirs, search instantly. Opens on Enter for path fields.

End-to-End Flow

What happens when you migrate a VM from VMware vSphere to KubeVirt.

StepComponentWhat HappensTime
1. DiscoverGo hypersdk / govcConnect to vCenter via SOAP API. List VMs with govc ls + vm.info -json. Return CPU, RAM, disk size, power state.5-15s
2. ExportGo hypersdkgovc export.ovf downloads VMDK via HttpNfcLease. Fallback: OVA, then HTTPS /folder. Progress streamed via \r lines.5-60 min
3. ValidatePy quality/Parse VMDK descriptor. Check extent sizes. Detect boot mode (BIOS/UEFI) via virt-inspector. Risk analysis (adapter type, geometry).2-5s
4. FlattenPy converters/qemu-img convert merges snapshot chain into single self-contained qcow2. Progress reported at 1% intervals.1-10 min
5. Guest FixPy fixers/Mount via qemu-nbd. Fix fstab (UUID). Rebuild initramfs (virtio). Fix GRUB. Remove VMware tools. SELinux relabel trigger.30-120s
6. DeployPy libvirt/ + pipeline/Generate libvirt domain XML (machine=q35, UEFI if detected). virsh define. OR: create KubeVirt VirtualMachine + PVC, upload via virtctl.5-30s
7. VerifyPy quality/Start VM in KVM. Wait for boot. Check no kernel panic. Verify network. Report pass/fail.30-60s

Deployment Options

Multiple ways to run the platform.

💻

CLI (h2kvmctl)

Single command or YAML config. Best for scripts, CI/CD, cron jobs. No daemon needed.

sudo h2kvmctl --config migration.yaml
🎮

TUI (zkvm)

Interactive terminal UI. Guided steps, file browser, vSphere discovery. Best for operators.

./zkvm/zkvm
🔧

Daemon (hypervisord)

REST API on :9292. Job queue, scheduling, webhooks. Best for automation platforms.

hypervisord --config /etc/hypersdk/config.yaml
☸️

K8s Operator

CRDs for migration jobs. Helm chart. GitOps-friendly. Best for K8s-native teams.

helm install hypersdk ./helm/hypersdk
🐳

Container

OCI image for Podman/Docker. Mount disks as volumes. Best for CI/CD pipelines.

podman run -v ./:/data hypersdk convert
🌐

Distributed (Agent)

gRPC agents near source infra. Control plane aggregates. Best for multi-site.

hypersdk-agent --control-plane=hq:9393
