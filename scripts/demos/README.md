# Demo Scripts

Demonstration scripts for showcasing hyper2kvm features and capabilities.

## Available Demos

### TUI Demonstrations

- **show_tui_preview.py** - TUI preview and demonstration
  - Shows the TUI dashboard in action
  - Demonstrates orange theme
  - Preview of interactive features

- **show_progress_bars.py** - Progress bar demonstrations
  - Various progress bar styles
  - Custom orange-themed progress indicators
  - Real-time progress tracking examples

- **show_implementations.py** - Implementation demonstrations
  - Shows different feature implementations
  - Code examples and usage patterns

## Usage

Run any demo script directly:

```bash
# TUI preview
python scripts/demos/show_tui_preview.py

# Progress bars
python scripts/demos/show_progress_bars.py

# Implementations
python scripts/demos/show_implementations.py
```

## Requirements

Some demos may require optional dependencies:

```bash
pip install 'hyper2kvm[tui]'
```
