The Problem

Migrating VMs between hypervisors is painful and error-prone:

  • Disk format incompatibility — VMDK, VHDX, VHD, OVA all need conversion
  • Boot failures — wrong drivers, broken GRUB, stale fstab entries
  • Manual intervention — trial-and-error fixing after each attempt
  • No Windows support — VirtIO drivers must be injected manually
  • No automation — each VM is a one-off effort
Traditional approach:

Convert → Boot → Hope

❌ ~40% first-boot failure rate

Code Example

from h2kvm.core.vmcraft import VMCraft

with VMCraft() as g:
    g.add_disk("/vms/server.qcow2")
    g.launch()  # ~1.9 seconds

    # Inspect OS
    os_info = g.inspect_os()
    print(f"OS: {os_info.product_name}")

    # Read/write files
    g.write("/etc/motd",
            "Migrated to KVM!\n")

    # Partition & LVM management
    parts = g.list_partitions()
    vgs = g.vglist()

Migration Workflow

Step 1: Configure (YAML)

cmd: local
vmdk: /path/to/server.vmdk
output_dir: /output
to_output: server.qcow2
out_format: qcow2
fstab_mode: stabilize-all
regen_initramfs: true
no_grub: false
libvirt_test: true

Step 2: Run

# One command migration
sudo h2kvmctl \
  --config migration.yaml

Step 3: Deploy

# Deploy to libvirt
sudo virsh define server.xml
sudo virsh start server

# Verify
sudo virsh domifaddr server

Or: Direct to K8s

# One-command K8s deploy
sudo h2kvmctl \
  --config migration.yaml \
  --deploy-k8s \
  --k8s-namespace prod \
  --k8s-vm-name web-01 \
  --k8s-auto-start
Automated:
1. Convert + fix
2. Upload to PVC
3. Create KubeVirt VM
4. Start & verify

Getting Started

Installation

# Install with all features
pip install "h2kvm[full]"

# Or minimal install
pip install h2kvm

System Dependencies (Optional)

# Fedora / RHEL
sudo dnf install -y \
  qemu-img qemu-system-x86

# Ubuntu / Debian
sudo apt-get install -y \
  qemu-utils qemu-system-x86

# Windows migration support
sudo dnf install -y \
  ntfs-3g libhivex-bin

CLI Commands

# Interactive CLI (recommended)
h2kvmctl --version

# Daemon / systemd mode
h2kvm --version

# Both are identical
