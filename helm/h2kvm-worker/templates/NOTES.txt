Thank you for installing {{ .Chart.Name }}!

Your h2kvm workers have been deployed.

To verify your installation:

1. Check worker pods:
   kubectl get pods -n {{ .Release.Namespace }} -l app=h2kvm-worker

2. View worker capabilities:
   export POD=$(kubectl get pods -n {{ .Release.Namespace }} -l app=h2kvm-worker -o jsonpath='{.items[0].metadata.name}')
   kubectl exec -n {{ .Release.Namespace }} $POD -- python3 -m h2kvm.worker.cli capabilities

3. Check PVCs:
   kubectl get pvc -n {{ .Release.Namespace }}

To submit a job:

1. Create job specification (see examples in k8s/worker/examples/)
2. Copy to worker pod:
   kubectl cp job.json {{ .Release.Namespace }}/$POD:/var/lib/h2kvm/job.json
3. Execute:
   kubectl exec -n {{ .Release.Namespace }} $POD -- \
     python3 -m h2kvm.worker.cli run /var/lib/h2kvm/job.json --follow
